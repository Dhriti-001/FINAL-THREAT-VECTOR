🛑 1. Problem Statement

Most existing cybersecurity learning platforms are overly complex and technical, making it intimidating for school and college beginners to start practicing security concepts.

💡 2. Proposed Solution

Threat Vector is a simplified, beginner-friendly cybersecurity training platform that offers intuitive simulation drills, AI-assisted threat analysis, and hands-on CTF challenges in one place.

🎯 3. Key Objectives

  • Provide a beginner-friendly sandbox for students to practice cyber defense without technical friction.
  • Offer AI-driven explanation and inspection of suspicious text, email headers, and URLs.
  • Feature gamified CTF challenges and drills to build foundational security skills progressively.

🏗️ 4. Project Architecture

The application uses a serverless Python Flask architecture with a local SQLite database for zero-dependency deployment. It integrates a Scikit-learn machine learning pipeline and Jinja2 frontend views to handle real-time threat analysis and synchronous routing.

🚀 5. Next Milestone

Expand the platform's content library to dynamically generate a larger variety of interactive drills, CTF challenges, and war room scenarios for continuous learning.
