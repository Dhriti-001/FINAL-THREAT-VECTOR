🎓 College Viva Concept: How This Machine Learning Model Operates

1. TF-IDF Tokenization Converts document text into numerical feature vectors by balancing term frequency against inverse document frequency, giving high mathematical weights to rare attack indicators like 'urgent', 'otp', and '.top'.
2. Logistic Regression Classifier Maps arbitrary linear weights $z = \mathbf{w}^T \mathbf{x} + b$ through the logistic sigmoid function $\sigma(z) = \frac{1}{1 + e^{-z}}$ to calculate a calibrated posterior probability between 0% (Benign) and 100% (Malicious).
3. Heuristic Rules Augmentation Complements statistical machine learning with deterministic regex guards to capture domain typosquatting, high-risk TLDs, and executable payloads.
